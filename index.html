Projects

VisionMate

An NVDA add-on for Windows that describes images with AI, locally on your computer. Describe the current element, the whole screen or a clipboard image. Press once for a quick spoken description, twice for a detailed one in a window you can copy from. Automatic descriptions of unlabeled images are optional and off by default.

After a one-time model download of about 1.5 GB it works offline, with no account, no API key and no cloud upload. Requires Windows 10 or 11 (64-bit) and NVDA 2024.1 or later. Source is publicly available under GPL v2 or later.

VisionMate on GitHub

Beyond Pixels

An Android photo gallery for blind and low-vision users. Browse photos and albums, get optional AI-generated descriptions, listen with read-aloud support, give photos custom names and set accessibility preferences. Available on Google Play.

Beyond Pixels on Google Play | Beyond Pixels website

Edge TTS for NVDA

An NVDA add-on and Android text-to-speech engine that brings Microsoft Edge's online neural voices (300+) to the NVDA screen reader on Windows, or to Android as a system TTS engine. Independent project, not affiliated with Microsoft.

Edge TTS for NVDA on GitHub | Project page

Web Accessibility Heuristic Enhancer (a11y-engine)

A userscript that improves accessibility on websites as you browse: adds ARIA roles and labels to unlabeled buttons, links and form fields, adds keyboard support, handles focus in modal dialogs and announces infinite-scroll updates. Changes can be rolled back.

a11y-engine on GitHub
