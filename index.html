About

I am an accessibility tester based in Chennai, India, and a screen reader user myself.

I test websites and apps for accessibility, so I know first-hand what works and what blocks people who rely on a screen reader. Outside work I build tools for blind and low-vision people: NVDA add-ons, userscripts and Android apps. I am also offering accessibility and building services to others.

Projects

Tools and apps I have built for blind and low-vision users.

  • VisionMate

    NVDA add-on for Windows

    Describes images with AI, locally on your computer. Describe the current element, the whole screen or a clipboard image. Press once for a quick spoken description, twice for a detailed one in a window you can copy from. Automatic descriptions of unlabeled images are optional and off by default.

    After a one-time model download of about 1.5 GB it works offline, with no account, no API key and no cloud upload. Requires Windows 10 or 11 (64-bit) and NVDA 2024.1 or later. The source is publicly available under GPL v2 or later.

    VisionMate on GitHub

  • Beyond Pixels

    Android photo gallery

    A photo gallery for blind and low-vision users. Browse photos and albums, get optional AI-generated descriptions, listen with read-aloud support, give photos custom names and set accessibility preferences. Available on Google Play.

    Beyond Pixels on Google Play Beyond Pixels website

  • Edge TTS for NVDA

    NVDA add-on and Android text-to-speech engine

    Brings Microsoft Edge's online neural voices (300+) to the NVDA screen reader on Windows, or to Android as a system text-to-speech engine. An independent project, not affiliated with Microsoft.

    Edge TTS for NVDA on GitHub Project page

  • Web Accessibility Heuristic Enhancer (a11y-engine)

    Userscript for websites

    Improves accessibility on websites as you browse: adds ARIA roles and labels to unlabeled buttons, links and form fields, adds keyboard support, handles focus in modal dialogs and announces infinite-scroll updates. Changes can be rolled back.

    a11y-engine on GitHub
